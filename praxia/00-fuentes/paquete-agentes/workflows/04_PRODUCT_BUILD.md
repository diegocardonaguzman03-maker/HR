# 04 Product Build

**Status:** proposed SOP; configure live permissions before use.

**Shared exit standard:** each stage produces handoff JSON, source references, status, acceptance criteria and named next owner. Gate failures return to previous owner.

1. **DEV-01** — Define problem and measurable objective.
2. **UX-01** — Research and journey mapping.
3. **UI-01** — Accessible designs.
4. **DEV-02** — Build prototype with tests.
5. **DEV-03** — AI evaluation and automation checks.
6. **RISK-01** — Privacy/security risk review.
7. **QA-01** — Acceptance testing.
8. **Founder** — Approve deployment.
9. **CX-01** — Track support, issues and adoption.
