## A. Performance criteria
★ = **critical step**. All critical steps must be performed correctly. One failure means *not yet competent*.

| # | Step | ★ | Performed correctly | Not performed / incorrect | Comment |
|---|---|---|---|---|---|
| 1 | Identifies the equipment and reviews the isolation procedure / energy diagram | ★ | | | |
| 2 | Notifies the area operator and affected personnel | | | | |
| 3 | Identifies **all** energy sources (electrical, mechanical, hydraulic, pneumatic, thermal, gravitational, chemical) | ★ | | | |
| 4 | Stops the equipment using the normal procedure | | | | |
| 5 | Isolates each source at the correct isolation point | ★ | | | |
| 6 | Applies a personal lock and tag at each point / group lockbox | ★ | | | |
| 7 | Releases or controls stored energy (bleeds, blocks, discharges) | ★ | | | |
| 8 | **Verifies zero energy** (try-start test, voltage test with a checked tester) | ★ | | | |
| 9 | Completes the permit / isolation register | | | | |
| 10 | Correct removal sequence: checks the area, people clear, removes own lock only | ★ | | | |
