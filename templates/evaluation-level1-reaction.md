# Course Evaluation — Level 1 (Reaction)

*Process TD-P06. Completed by each participant at the end of the course (LMS, QR code or paper).*

Course: ________ Code: ______ Date: ______ Instructor: ________ Site: ______

Scale: 1 = Strongly disagree · 5 = Strongly agree

| # | Statement | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | The content is relevant to my daily work. | | | | | |
| 2 | I can apply what I learned right away. | | | | | |
| 3 | I feel confident performing the task / applying the skill. | | | | | |
| 4 | The instructor knew the topic and explained it clearly. | | | | | |
| 5 | There was enough practice (hands-on / simulator / field). | | | | | |
| 6 | The materials were clear and in plain language. | | | | | |
| 7 | The duration was right. | | | | | |
| 8 | The facility, equipment and safety conditions were suitable. | | | | | |
| 9 | I would recommend this course to a coworker. | | | | | |

**Open questions**
- What will you apply first in your job?
- What would you change about the course?
- What could stop you from applying it (equipment, procedures, supervisor, time)?

*Thresholds: an average below 4.0 triggers a course review; an instructor or vendor below 4.0 twice triggers corrective action (TD-P12).*
